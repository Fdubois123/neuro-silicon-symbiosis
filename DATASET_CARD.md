# Dataset Card

## Public Repository Dataset

The public Neuro-Silicon Symbiosis repository will use synthetic or publicly redistributable demonstration data.

## Restricted Data

ADNI and other controlled-access datasets will not be committed to this repository.

Users must obtain their own authorization and place restricted datasets locally according to the project documentation.

## Planned Modalities

- MRI
- EEG
- Genomics
- Proteomics
- Behavioral
- Cognitive
- Clinical metadata

## Data Safety

Sensitive or personally identifiable clinical information must never be committed to the public repository.
