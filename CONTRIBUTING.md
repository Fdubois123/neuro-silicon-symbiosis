# Contributing to Neuro-Silicon Symbiosis

Thank you for contributing.

## Development Principles

- Preserve scientific reproducibility.
- Keep demo data clearly separated from real research data.
- Never commit restricted or sensitive datasets.
- Add tests for meaningful functionality.
- Keep frontend, backend, and ML responsibilities modular.
- Document major architectural decisions.
- Use descriptive Git commit messages.

## Commit Style

Examples:

feat: add interactive brain scene
fix: correct resilience calculation
docs: update research methodology
test: add API validation tests
refactor: simplify fusion pipeline
